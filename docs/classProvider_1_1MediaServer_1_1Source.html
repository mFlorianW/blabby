std::unique_ptr< Multimedia::PendingPage > Provider::MediaServer::Source::browsePage ( QString const &  path,
qsizetype  startIndex 
)
overridevirtualnoexcept

Requests the page of the Items of the Container at the path that starts at the index, independent of the navigation: the mediaItems() and the current Container stay. The Source decides how many Items a page holds, a page without Items ends the Container. A paged Source must implement it, the default implementation gives a finished page without Items. The page may already be finished when it's given.

Parameters
pathThe path of the Container.
startIndexThe index of the first Item of the page.
Returns
The page, it finishes later or is finished already.

◆ loadMore()

void Provider::MediaServer::Source::loadMore ( )
overridevirtualnoexcept

Disable copy or move

Loads the next page of Items of the current Container and appends them to the mediaItems(). This loadMore() must only be implemented when the Source is paged, the default implementation does nothing. The Source shall emit the moreItemsLoaded() signal when the page is loaded. If it fails to load the page the Source shall emit the loadingMoreFailed() signal instead, and keep its mediaItems() unchanged.
