Detailed Description

This model provides a list based access to all known Multimedia::Renderer, Online and Offline. The Online Multimedia::Renderer come before the Offline ones, each ordered alphabetically by name.

◆ activateRenderer()

void Shell::MediaRendererModel::activateRenderer ( QModelIndex const &  index)

Makes the Multimedia::Renderer under the passed QModelIndex the Active Renderer. Active means in this case that the renderer is used for playback. The playback of the previous Active Renderer is not touched. If the index is invalid, the Multimedia::Renderer is Offline or already active nothing happens.

void Shell::MediaRendererModel::forgetRenderer ( QModelIndex const &  index)

Forgets the Offline Multimedia::Renderer under the passed QModelIndex, it's removed from the remembered Renderers and from the model. When it's discovered again it's listed as a newly seen Renderer. If the index is invalid or the Multimedia::Renderer is Online nothing happens.

◆ activeRenderer

std::shared_ptr<Multimedia::Renderer> Shell::MediaRendererModel::activeRenderer
read

This property holds the Active Renderer, the Multimedia::Renderer that is used for playback. The Active Renderer is set via the MediaRendererModel::activateRenderer and is nullptr until a Multimedia::Renderer is activated or when the Active Renderer goes Offline.

◆ scanning

bool Shell::MediaRendererModel::scanning
read

This property is true while a discovery of Multimedia::Renderer on the network is running. A discovery is started on creation and by MediaRendererModel::rescan and ends when the Multimedia::Renderer on the network had the time to answer it.
