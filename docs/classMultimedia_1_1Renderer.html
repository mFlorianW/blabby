Detailed Description

A Mulitmedia::MediaRenderer represents a hardware device that can control and play Mulitmedia::MediaItem

◆ goOffline()

void Multimedia::Renderer::goOffline ( )
noexcept

Makes the Multimedia::Renderer Offline, e.g. when it leaves the network. The Multimedia::Renderer also goes Offline by itself when its device doesn't answer a call or its event subscription anymore, a device that answers with an error stays Online. The last known details are kept, the Playback State becomes No Media, the volume 0 and all requests are ignored until the Multimedia::Renderer is Online again. The signal Multimedia::Renderer::availabilityChanged is emitted when the Availability changed.

◆ goOnline()

void Multimedia::Renderer::goOnline ( std::unique_ptr< UPnPAV::MediaRenderer >  mediaRenderer)

Makes the Multimedia::Renderer Online with the passed device, e.g. when it's discovered again. The details are refreshed from the device, the device must have the identity of the Multimedia::Renderer. An initialized Multimedia::Renderer is initialized again for the new device. The signals Multimedia::Renderer::availabilityChanged and Multimedia::Renderer::detailsChanged are emitted when the Availability or the details changed.

Parameters
mediaRendererThe UPnPAV::MediaRenderer that shall be controlled by this Multimedia::Renderer.

◆ resume()

void Multimedia::Renderer::resume ( )
noexcept

Resumes the playback when the Multimedia::Renderer has the state Mulitmedia::Renderer::State::Stopped or Mulitmedia::Renderer::State::Paused. If the device is in the stopped state the playback starts all over again and for the pause state the track resumes at the pause state. In all other cases the function does nothing. On failure the signal Multimedia::Renderer::controlFailed is emitted with the action Play or Resume.

◆ setPositionTracked()

void Multimedia::Renderer::setPositionTracked ( bool  tracked)
noexcept

Switches the tracking of the position on or off, e.g. for the Active Renderer only. While tracked and Playing, the Multimedia::Renderer requests its position info every second, a request is skipped while the previous one is pending. While tracked it also requests it right away after every Playback State change, when it goes Online and when the tracking is switched on. Nothing is requested otherwise.

Parameters
trackedTrue switches the tracking on, false switches it off.

◆ stop()

void Multimedia::Renderer::stop ( )
noexcept

Stops or pause the current playback. Pause is the preferred way to stop the playback but not every device support this feature. So the pause is called when the device supports it in all other cases stop is called. If the playback is not active nothing happens. On success the signal Multimedia::Renderer::stateChanged is emitted. The new state then should be be stopped or paused. On failure the signal Multimedia::Renderer::controlFailed is emitted with the action Pause or Stop.
