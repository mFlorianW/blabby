Detailed Description

Base class for every Provider plugin. A derived class of this has to implement the init function. The init will be autommatically called by the ProviderLoader on application start.

QList< ProviderSetting > Multimedia::Provider::settings ( ) const
virtualnoexcept

Gives the settings of the Provider in the order the shell shows them. The Provider never reads or writes their values itself, the shell keeps them and passes them with Provider::setSettingValue() and the taps on an action with Provider::triggerAction().

Note
The default implementation returns an empty list, the Provider has no settings.
