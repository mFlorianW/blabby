Detailed Description

Base class for every media source. Each MediaSource shall have a name, optional icon. A MediaSource is a navigatable source of media items. Concrete subclasses must implement the navigate(QString, qsizetype) function. Subclasses that are not navigatable, all playable items are on the root layer. Those subclasses don't need to overwrite the default implemenation.

Requests the page of the Items of the Container at the path that starts at the index, independent of the navigation: the mediaItems() and the current Container stay. The Source decides how many Items a page holds, a page without Items ends the Container. A paged Source must implement it, the default implementation gives a finished page without Items. The page may already be finished when it's given.

◆ loadMore()

void Multimedia::Source::loadMore ( )
virtualnoexcept

Loads the next page of Items of the current Container and appends them to the mediaItems(). This loadMore() must only be implemented when the Source is paged, the default implementation does nothing. The Source shall emit the moreItemsLoaded() signal when the page is loaded. If it fails to load the page the Source shall emit the loadingMoreFailed() signal instead, and keep its mediaItems() unchanged.

void Multimedia::Source::navigate ( QString const &  path,
qsizetype  minimumItemCount 
)
protectedvirtualnoexcept

The source shall navigate to the given path, after a successful navigation the mediaItems() must be updated. A paged Source loads the first page of the Container, or more pages until at least the minimum number of Items is loaded or the Container has no more Items, see loadMore(). This navigate(QString, qsizetype) must only be implemented when the source is navigable. The default implementation does nothing. The source shall emit the navigationFinished(QString) signal when the navigation finished successfully. If it fails to navigate to the given path the source shall emit the navigationFailed(QString) signal instead, and keep its mediaItems() unchanged.

Parameters
pathThe target path to navigate to.
minimumItemCountHow many Items shall be loaded at least.
