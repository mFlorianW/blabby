Detailed Description

The MediaItemModel provides access to the item of a media source and make it possible to navigate them. The Items of a large Container are fetched page by page through Qt's fetch more, see canFetchMore().

Activates the Multimedia::MediaItem under the passed index. Activating a Container opens it. Activating a Playable requests to play it, see playRequested. Any activation while isBusy() does nothing.
