Detailed Description

The sections of the Settings screen, one model row per section, and the rows of the picked section. The first section is Renderers, it is picked from the start and has the "Remember last Renderer" switch. It is followed by one section for each Provider that describes at least one setting, ordered by title. The last section is About, it shows the Blabby version, the Qt version and every loaded Provider with its version. At start each Provider gets the values of its switches, the stored ones or else the defaults.
