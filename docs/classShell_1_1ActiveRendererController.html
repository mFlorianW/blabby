Detailed Description

The Shell::ActiveRendererController follows the Active Renderer of a Shell::MediaRendererModel and gives the Playing screen what it shows of it. Without an Active Renderer it has no name, its Playback State is No Media and it has no Current Track. The position of the Active Renderer is tracked, the one of the previous is not.
